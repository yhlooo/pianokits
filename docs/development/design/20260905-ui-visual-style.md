## 0. 一句话方向

**"乌木舞台，象牙发声"（Ebony stage, ivory voice）**：界面是音乐厅里暗下来的观众席，钢琴键、
纸张、音符是被聚光灯照亮的部分。高级感 = 克制（少量色相、少量装饰）+ 精密（统一网格、
字阶、动效曲线）+ 材质（纸张、象牙键、金属件各自的质感差异）。

品牌天然支持这个方向：favicon 已经是乌木底 + 象牙键；ROLI Learn 2025 改版同样从蓝色转向
ebony & ivory，理由是"更平静、对比更清晰、帮助聚焦"（见参考文档）。

## 2. 设计原则

1. **克制用色**：全局只有一个强调色家族；功能性颜色（危险/成功）降饱和、只在需要时出现。
2. **层次靠明度，不靠描边**：用 4 级表面明度区分层级；1px 边框降级为低透明发丝线，只用于真正需要的分隔。
3. **一切有秩序**：4px 基准网格、固定字阶、统一控件高度（32px）、统一圆角档位。
4. **动效即品质**：hover/选中/视图切换全部有 120–240ms 缓动；但播放中的视觉元素（瀑布流、高亮）不做插值动画——它们与音频时钟绑定，精确优先。
5. **材质要诚实**：谱面是"纸"、键盘是"象牙/乌木"、控件是"深色金属件"，各自有 subtle 的质感差异（纸用暖白+软影，键用微渐变，金属件用发丝高光）。
6. **可访问性不妥协**：正文对比度 ≥ WCAG AA（4.5:1），焦点环可见，支持 `prefers-reduced-motion`。

## 3. 色彩

### 3.1 中性色阶（乌木系，微暖）

现状的 `#101014 / #18181d / #1f1f26` 偏蓝灰且层级拉不开。改为微暖乌木阶：

| token           | 值                       | 用途                          |
| --------------- | ------------------------ | ----------------------------- |
| `--bg-0`        | `#121110`                | 应用底色（观众席）            |
| `--bg-1`        | `#1A1917`                | 面板（侧栏、工具条）          |
| `--bg-2`        | `#232220`                | 抬升面（卡片、选中底、hover） |
| `--bg-3`        | `#2E2C29`                | 更高抬升（弹层、tooltip）     |
| `--line`        | `rgba(255,255,255,0.07)` | 发丝分隔线                    |
| `--line-strong` | `rgba(255,255,255,0.12)` | 控件描边                      |
| `--text-0`      | `#F2F0EC`                | 主文本（暖白）                |
| `--text-1`      | `#B8B5AE`                | 次文本                        |
| `--text-2`      | `#807D76`                | 弱文本（元信息、hint）        |

### 3.2 强调色：音乐厅琥珀（**2026-09-05 已决策，Q1 → 方案 A**）

`--accent: #D9A45B`，hover `#E4B871`，按下 `#C2914A`，淡底 `rgba(217,164,91,0.14)`。
香槟金打在乌木上，是三角钢琴漆面 + 舞台聚光灯的联想；与象牙键、暖白纸谱同属暖色系，
全局色彩统一度最高。键盘点亮、播放高亮、主按钮、选中态全部用它。

（落选记录：方案 B 精制靛蓝 #8079F2——改动小但"通用 SaaS 感"较重，与暖色材质有色相冲突。）

**取消青色 `--accent-2`**（现状键盘点亮的 #22d3ee 与谱面高亮 #0e7490 是第三、第四个
色相，全部并入 accent 家族；瀑布流左右手双色见 §6.4，左手色是唯一例外）。

### 3.3 语义色

| token          | 值        | 用途                                         |
| -------------- | --------- | -------------------------------------------- |
| `--danger`     | `#E0695E` | 删除 hover、错误（降饱和，不再用纯 #ef4444） |
| `--success`    | `#7FB285` | 导入完成等                                   |
| `--paper`      | `#FAF7F1` | 谱面纸张（暖象牙，替代纯 #fff）              |
| `--paper-text` | `#1C1A17` | 纸面记谱颜色（谱号/音符，近黑微暖）          |

### 3.4 键盘材质

- 白键：顶 `#F4F1EB` → 底 `#E3DFD7` 微渐变，键底 1px `#C9C4B9` 阴影线；
- 黑键：顶 `#2A2825` → 底 `#141312` 微渐变，顶边 1px `rgba(255,255,255,0.08)` 高光；
- 点亮键：accent 填充 + 外发光（accent 40% 透明，blur 12px），替代现在的青色。

## 4. 字体排印

- UI 正文保持系统栈（零加载成本），数字统一 `font-variant-numeric: tabular-nums`；
- **品牌字标与谱面标题引入自托管衬线展示字**（**2026-09-05 已决策，Q4 → 引入**）：
  首选 EB Garamond（OFL 许可），备选 Playfair Display（OFL）；woff2 拉丁子集约 30–60KB，
  进 `public/fonts/` 自托管，**禁止运行时外链**；只用于品牌字标、空状态标题等大字号，
  正文/控件不用（中文衬线字体积不可控，不做）；
- 字阶（rem）：0.6875 / 0.75 / 0.8125 / 0.875 / 1 / 1.25 / 1.75，对应 caption/meta/body/
  body-strong/标题/面板标题/品牌；字重只用 400/500/600/700；
- 全角中文与西文混排时，时间、进度等纯数字串用等宽数字；品牌字 `letter-spacing: 0.02em`。

## 5. 间距、圆角、阴影、动效

- **间距**：4px 基准网格，常用档位 4/8/12/16/24/32；侧栏内边距 16，面板区间隔用明度差
  替代 1px 网格线（`.stage` 的 `gap:1px; background: border` 技巧废弃）；
- **圆角**：6（小控件）/ 10（按钮、列表项）/ 14（纸张卡片）；不再全局统一 6px；
- **阴影**（仅抬升元素，平面元素不用）：
  - 卡片：`0 1px 2px rgba(0,0,0,0.35)`；
  - 纸张：`0 2px 6px rgba(0,0,0,0.35), 0 12px 32px rgba(0,0,0,0.30)`；
- **动效**：`--ease-out: cubic-bezier(0.22, 0.61, 0.21, 1)`；hover/选中 120ms，面板/视图
  切换 200ms，通知进出 240ms；`@media (prefers-reduced-motion: reduce)` 全部归零；
- **图标**：废弃文本字形（▶ ⏹ ↻ ×）与 emoji（🔊），改为内联 SVG 图标集：20×20 视窗、
  1.5px 描边、圆角线帽、单色 `currentColor`；播放/暂停用实心字形，其余用描边。

## 6. 分区指南

### 6.1 外壳顶栏（48px）

- 品牌只出现一次：左侧 favicon 琴键小图标 + "PianoKits"（若 Q4 采纳则用展示衬线字）；
- 工具页签改为"文字页签"：无框、弱文本色，当前页签 = 主文本色 + 底部 2px accent 短指示条；
- 删除工具条里的第二个品牌字样（`.transport__brand`）。

### 6.2 工具条（播放器条）

- **底部播放坞**（2026-09-05 按其要求：顶部不放任何控制按钮，播放控制整体下移）：
  钉在页面最底部、只占左侧栏右边的内容区（侧栏通高到底），坞顶边为 1px 发丝线；
  - 上沿：通栏进度条（16px 高，3px 轨道，已播放段 accent 填充；拇指平时隐藏，
    悬停/拖拽/聚焦时浮现 12px 圆形拇指）；
  - 控制行（46px）：播放/停止为 36×36 图标按钮（ghost 风格，hover 出 `--bg-2` 底），
    时间码（等宽数字）紧随其后；右端为音量与视图切换；
- 音量：喇叭 SVG 图标 + 80px 自绘滑块（4px 轨道 + 常显拇指）；
- 视图切换改为**分段控件**（macOS segmented 风格）：一个 10px 圆角容器内三个无框段，
  当前段 = `--bg-3` 底 + 主文本色，而不是三颗独立按钮；
- 采样加载：播放按钮位置改为环形进度（stroke accent），补上 `engineProgress` 的渲染
  （修复现状"有数据无 UI"的缺口）。

### 6.3 文件库（侧栏 264px）

- 头部一行：`文件库` 面板标题 + 右侧小型 accent 图标按钮（＋导入），不再用通栏大 CTA；
- hint 文本合并进空状态；列表项两行结构（名称截断单行 + 元信息单行：
  `941 KB · 3 分钟前` 相对时间），选中态 = `--bg-2` 底 + 左侧 2px accent 竖条（替代整条
  1px 描边）；删除/重导图标按钮仅 hover 该行时淡入；
- 空状态：居中钢琴键 SVG 剪影 + 两行引导文案 + 次级"导入 MIDI"描边按钮；整个列表区兼作
  拖放区（dragover 时显示 accent 虚线框）。

### 6.4 瀑布流

- 背景：自上而下 `#121110` → `#161514` 微渐变；每个 C 音位置画 1px `rgba(255,255,255,0.04)`
  纵向音区参考线（Q3 未单独讨论，按推荐默认：**只画音区参考线，不加拍网格横线**）；
- 音符条：**左右手双色（2026-09-05 已决策，Q2）**——右手 = 琥珀 accent
  （顶 `#E4B871` → 底 `#C2914A`），左手 = 低饱和钢蓝（顶 `#8FA8C4` → 底 `#5F7694`，
  乌木上的冷色伴奏层，与琥珀是经典互补且都压低了饱和度，避免重蹈靛蓝+青色的互相争抢）；
  双色基础上保留力度映射：velocity 在各自手色内调制明度（弱音更暗更淡）；
  音符条顶部 1px 高光边、纵向两档渐变不变；
- 判定区：键盘上沿用 2px accent 渐变光带提示（克制，非霓虹）；
- 点亮键：**颜色跟随音符手色**（2026-09-05 按其要求修正）——右手音符点亮琥珀、
  左手音符点亮钢蓝，各带同色系柔光（见 §3.4）；按压带 80ms 渐隐，避免生硬跳变；
- **琴键比例（2026-09-05 修复）**：键宽随容器宽度变化，键盘高度不固定死——按真实
  白键宽长比 1 : 6.3（23.6mm × 150mm）随键宽换算，并钳制在 44–140px 之间；
  分屏与全宽下琴键长宽比保持一致，不再出现全宽时"又宽又矮"的视觉拉伸。

### 6.5 五线谱

- 纸张从纯 `#fff` 改为暖象牙 `--paper`（#FAF7F1）（**2026-09-05 已决策，Q5**；深色谱面
  模式本轮不做），圆角 14px，加 §5 的纸张阴影，系统间距 16px，卡片内边距加大到
  20–28px——目标是"一叠放在深色谱架上的乐谱"，而不是"贴在黑墙上的白纸"；
- 记谱墨色从纯黑改为 `--paper-text`（近黑微暖）；
- 播放高亮并入 accent 家族（纸面上用加深版琥珀 `#A8772E`），替代现在的深青 #0e7490；
- 顶部提示条从分隔带改为行内小字 caption（弱文本色，无背景无底线）。

### 6.6 通知与反馈

- 错误通知从通栏暗红横幅改为顶部居中的浮动胶囊（`--bg-3` + 危险色左边条 + 关闭按钮），
  6 秒自动消退；导入完成用 success 胶囊。

## 7. 不做的事（防止"高级感"跑偏）

- 不做玻璃拟态（backdrop-blur 叠霓虹）、不做彩虹渐变、不用阴影堆砌层级；
- 不让两个高饱和色相同屏竞争（现状靛蓝+青色的教训）；
- 不给播放中的实时视觉加装饰性动画（精确同步优先）；
- 不引入图标字体/外部字体 CDN（运行时零外链的约束不变）。
