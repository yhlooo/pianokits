# 使用指南：MIDI 导入与播放

pianokits 的第一个工具：导入钢琴 MIDI 文件，浏览器本地保存文件列表，点选即用钢琴音色播放，
同步显示五线谱与钢琴瀑布流。

## 快速上手

1. 打开页面，点击左侧"**导入 MIDI**"，选择一个或多个 `.mid` / `.midi` 文件；
2. 文件会保存到浏览器本地（IndexedDB）——**刷新页面后列表仍在，无需重复导入**；
3. 点击列表中的文件条目即可加载；首次加载会同时预载钢琴采样（约 42MB，本地资源，通常数秒内完成，
   就绪前会以简易合成音色兜底，加载进度不影响使用）；
4. 点击顶部 **▶ 播放**。首次出声需要一次点击手势，这是浏览器自动播放策略的要求。

## 界面

- **顶栏（应用外壳）**：品牌 + 工具页签，用于在工具箱的不同工具间切换；
- **工具内工具条**：播放/暂停、停止、进度条（可拖动跳转）、时间、音量、视图切换；
- **视图切换三态**：分屏（瀑布流 + 五线谱并排）/ 瀑布流 / 五线谱；窄屏下分屏自动改为上下排；
- **文件库**：文件名、大小、导入时间；条目右侧 `↻` 重新导入更新快照、`×` 删除。

## 瀑布流

- 底部是 88 键钢琴键盘，**判定线就是键盘上沿**（画面中间没有任何判定线）；
- 音符条自上而下坠落：**条底落到琴键的瞬间就是发声时刻**，发声期间对应琴键点亮发光；
- 播放中视窗自动跟随（判定线始终对齐播放头）；
- **点击**音符区任意位置跳转到对应时间；**拖拽**上下平移时间窗（脱离跟随、预览后续音符）；
  **双击**恢复自动跟随；**滚轮**缩放时间轴（以指针为锚点）。

## 五线谱

- 双谱表（大谱表）记谱：以 C4（中央 C）为界分左右手；
- 播放中当前音符高亮，谱面自动滚动跟随；
- 谱面由 MIDI 自动转换而来，**定位是"跟随参考谱"，不是出版级乐谱**：
  - 量化到八分音符网格，跨拍长音用延音线连接；
  - 不含连音（三连音）自动检测、装饰音与复杂节奏的精确还原；
  - 若 MIDI 缺拍号/调号信息，按 4/4、C 大调兜底。

## 数据与隐私

- MIDI 文件以**内容副本**形式保存在浏览器 IndexedDB 中，不经过网络传输；
- 副本是导入时的快照：之后修改原文件不会反映到应用中，请用 `↻` 重新导入；
- 清除浏览器站点数据会同时删除文件列表与副本；
- 删除条目立即生效。

## 已知限制（M1）

- 默认合并所有非打击乐轨道播放；轨道级勾选在 M2 提供；
- 采样为 smplr `SplendidGrandPiano`（Steinway，AKAI 公有领域采样），本地自托管；
- 五线谱自动记谱仅供跟随参考（见上）。
