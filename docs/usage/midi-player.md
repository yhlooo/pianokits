# 使用指南：MIDI 导入与播放

pianokits 的第一个工具：导入钢琴 MIDI 文件，浏览器本地保存文件列表，点选即用钢琴音色播放，
同步显示五线谱与钢琴瀑布流；支持连接 MIDI 钢琴键盘实时演奏与跟谱练习。

## 快速上手

1. 打开页面，点击左侧"**导入 MIDI**"，选择一个或多个 `.mid` / `.midi` 文件；
2. 文件会保存到浏览器本地（IndexedDB）——**刷新页面后列表仍在，无需重复导入**；当前打开的
   文件名保存在 URL query 中，刷新后会自动重新打开；
3. 点击列表中的文件条目即可加载；首次加载会同时预载钢琴采样（约 42MB，本地资源，通常数秒内完成，
   就绪前会以简易合成音色兜底，加载进度不影响使用）；
4. 点击顶部 **▶ 播放**。首次出声需要一次点击手势，这是浏览器自动播放策略的要求。

## 界面

- **顶栏（应用外壳）**：品牌 + 工具页签，用于在工具箱的不同工具间切换；
- **工具内工具条**：播放/暂停、停止、进度条（可拖动跳转）、时间；
- **音量**：喇叭图标不再常显滑块——PC 端悬停喇叭图标在其上方展开竖向音量滑块、点击喇叭图标
  切换静音；触屏端点击喇叭图标展开/收起滑块，音量调到 0 即静音；
- **工具条右下角**：瀑布/乐谱视图开关（图标，开启用亮度表示）+ MIDI 键盘连接（钢琴图标）
  - 练习模式（打开的书图标）；
- **视图开关**：两个图标开关决定显示内容——瀑布 + 乐谱都开 = 分屏（左右并排，窄屏自动改上下排）、
  只开瀑布 = 瀑布流、只开乐谱 = 五线谱；两个开关不能同时关闭（关闭最后一个会自动开启另一个）；
- **音乐库**：文件名（不含 `.mid` 后缀）、大小、导入时间；条目 hover 显示 `×` 删除
  （触屏设备无 hover，删除按钮常显）。

## MIDI 键盘

工具条右下角的**钢琴图标**展示 MIDI 键盘连接状态（需要 Chrome / Edge / Firefox 等支持
Web MIDI 的浏览器）：

1. 进入播放器页面即**自动发起连接**（首次会请求浏览器授权）；授权后常驻，随时插拔键盘
   都会自动连上；
2. **未连接/无设备**：图标为暗色，悬停显示状态；点击弹出状态浮层（已连接键盘名列表 /
   等待插入 / 失败原因与“重连”）；
3. **连接中**：图标变为旋转等待动画，悬停显示“正在连接 MIDI 键盘…”；
4. **已连接**：图标变亮，悬停显示**已连接键盘的名称**；此时**按键即发声、离键即止音**
   （音色与当前播放引擎一致），可以随曲跟弹；
5. **同步发声到键盘**：若键盘带 MIDI 输出（自带音源的键盘），播放曲目时每个音符会
   **同步输出一份到键盘**，键盘自带音箱与电脑播放一起发声；暂停/停止会同时止住键盘
   上的长音，断开或拔出键盘后停止输出；
6. 设备热插拔自动感知：拔掉键盘后连接断开、练习模式自动退出；浏览器不支持 Web MIDI 时
   图标禁用，悬停可见提示。

## 练习模式

连接 MIDI 键盘后，点击**打开的书图标**开启练习模式（未连接时置灰不可用；开启时自动切到瀑布流视图）。
打开的书图标上方有**练习菜单**（桌面端悬停展开、触屏端点击展开/再点收起），可按轨开关练习：

- 音符条照常下落，但落到琴键（判定线）上**不会自动发声**，而是停住等待；
- 按下正在等待的音符对应的琴键，音符才会播放，然后后续音符继续下落，依此类推；
- **和弦**（同时多个音符）需要**同时按住全部琴键**才放行；多按、按错都不会触发，
  按错的键在键盘上**红色显示**，松开后红色消失；
- 提前按好琴键也可以：音符一到判定线立即放行；
- 播放/暂停/停止/拖拽跳转照常可用；暂停期间可以调整指法，恢复后按当前按住状态重新判定。

### 踏板练习

练习菜单的“练习音轨”分组列出各音轨（多选，仅对开启的音轨做按键判定）；下半部分是
**踏板**三选一（默认“关”）：

- **关**：只判琴键（踏板条全部变淡，表示无需关注）；
- **仅延音踏板**：只把延音踏板（右）纳入判定；
- **全部踏板**：弱音（左）/ 选择延音（中）/ 延音（右）都纳入判定。

判定口径：

- 音符落到判定线时，除了按对琴键，还要**同时踩下该处乐谱要求的踏板**才会继续播放，
  否则停在判定线等待（画面上的银白光晕指出需要踩哪个踏板）；踏板可以一直踩着，
  不要求在每次和弦时重踩；
- 踏板**分声部**：曲子里属于当前练习轨（同一 MIDI 通道）的踏板才判定；如果曲子的踏板
  不属于任何声部（例如单独的控制轨），则视为全曲踏板、所有练习轨都判定；
- 等待期间踩了不该踩的踏板：该踏板列与键盘交界处显示**红色光晕**，松开后消失，
  按对之后立即继续；
- 练习轨之外的踏板条、以及模式之外的踏板条会**变淡**（无需关注），也不显示触发光晕；
- 选择“仅延音踏板/全部踏板”时若还没有开启任何轨的练习，会自动开启全部轨
  （否则该设置无从生效）；切换踏板练习模式会自动暂停播放。

## 瀑布流

- 底部是 88 键钢琴键盘，**判定线就是键盘上沿**（画面中间没有任何判定线）；
- 音符条自上而下坠落：**条底落到琴键的瞬间就是发声时刻**，发声期间对应琴键点亮发光；
- **踏板事件条**：画面中央三列**银灰色**（接近灰度、刻意做得不抢眼）颜色条
  （左 = 弱音、中 = 选择延音、右 = 延音），条底落到键盘上沿的瞬间就是踏板踩下时刻、
  条高即时值；条是银灰色（上亮下暗），压在音符条**下面**（不会挡住音符）；踩下期间该列与
  键盘交界处亮起一块**圆角矩形的银白光晕**（与踏板条同宽或略宽、以交界线为高度中心，
  下半块被钢琴键盘挡住、不会盖到琴键），松开后消失。
  **只画踏板事件本身**：没有踏板事件的列、以及整曲没有踏板数据时，画面上不显示任何踏板轨道背景；
- 视窗自动跟随（判定线始终对齐播放头；暂停时拖动进度条或点击跳转也会同步跟随）；
- **点击**音符区任意位置跳转到对应时间；**拖拽**上下平移时间窗（脱离跟随、静音预览后续音符，
  拖动期间不发声，松开后若原本在播放则恢复发声）；**双击**恢复自动跟随；**滚轮**缩放时间轴（以指针为锚点）。

## 五线谱

- 双谱表（大谱表）记谱：以 C4（中央 C）为界分左右手；
- 播放中当前音符高亮，谱面自动滚动跟随；
- 谱面由 MIDI 自动转换而来，**定位是"跟随参考谱"，不是出版级乐谱**：
  - 量化到八分音符网格，跨拍长音用延音线连接；
  - 不含连音（三连音）自动检测、装饰音与复杂节奏的精确还原；
  - 若 MIDI 缺拍号/调号信息，按 4/4、C 大调兜底。

## 数据与隐私

- MIDI 文件以**内容副本**形式保存在浏览器 IndexedDB 中，不经过网络传输；
- 副本是导入时的快照：之后修改原文件不会反映到应用中；
- 清除浏览器站点数据会同时删除文件列表与副本；
- 删除条目立即生效。

## 已知限制（M1）

- 默认合并所有非打击乐轨道播放；轨道级勾选在 M2 提供；
- 采样为 smplr `SplendidGrandPiano`（Steinway，AKAI 公有领域采样），本地自托管；
- 五线谱自动记谱仅供跟随参考（见上）。
