# 使用指南：MIDI 录音（`/midi-recorder`）

用 MIDI 钢琴键盘即兴弹奏，把 MIDI 信号录成一条音轨，导出为 `.mid` 文件下载，或保存进
「MIDI 播放器」的本地音乐库。**录的是 MIDI 信号（音高/力度/时值），不是麦克风声音**；
播放也只经连接的 MIDI 键盘发声，本机不发声。

## 快速上手

1. 顶栏点击「**录音**」（页面 URI 为 `/midi-recorder`），进入即自动请求连接 MIDI 键盘
   （首次会弹浏览器授权提示）；
2. 连接成功后，点 **● 录制**，对着键盘弹奏——音符会在中央的录制线上出现，并随演奏向左移动；
3. 再点 **⏸** 暂停录制（可接着拖动音轨回到某个位置继续补录）；点 **▶ 播放** 可让键盘回放当前音轨；
4. 点 **⬇ 下载** 导出 `.mid` 文件，或点 **软盘** 保存到「MIDI 播放器」的音乐库；
5. 点 **■ 结束** 清空音轨（会二次确认）。

## 界面

```
        ┌──────────────────────────────────────────────┐
        │            00:12          已连接：Roland FP-30X│   ← 计时器（音轨位置）/ MIDI 状态
        ├──────┬───────────────────────────────────────┤
        │  C8  │                                       │
        │  …   │        ▮▮▮   ▮▮▮▮▮                    │   ← 音轨（钢琴卷帘）：一格一个半音，88 键
        │  C4  │             ╎  ← 录制/播放线（居中）    │
        │  …   │                                       │
        │  A0  │                                       │
        ├──────┴───────────────────────────────────────┤
        │        [▶]  [●]  [■]  [💾]  [⬇]              │   ← 控制按钮（居中）
        └──────────────────────────────────────────────┘
```

- **音轨**：纵向一行一个半音，显示钢琴全键盘 **88 键（A0~C8）**——低音区与最高音都能看到
  （88 键之外的 MIDI 音仍会被录制与导出，只是不画），
  最左列标注音名（`C4`、`D4`、`E4`…，行高足够时黑键音名也标注），每个音高一条浅横线、
  八度分界（C）更亮；
- **音符条**：长的方向是时值、颜色深浅是力度（越用力越亮）、高度位置是音高；
  录制中还没松开的音符会亮边显示，并一直画到录制线；
- **计时器**：显示录制/播放线所在位置，`分:秒.百分秒` 格式（如 `00:12.34`、`23:34.99`；
  超过 60 分钟继续累加，如 `99:23.45`、`102:23.45`）；
- **录制/播放线**：固定在音轨中央，录制时红色、播放时琥珀色；音轨内容向左移动即时间前进。

## 控制按钮

| 按钮            | 说明                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------ |
| ▶ 播放 / ⏸ 暂停 | 从录制/播放线位置开始，用连接的 MIDI 键盘回放；播放到末尾自动停；末尾再点播放从头开始      |
| ● 录制 / ⏸ 暂停 | 从录制/播放线位置开始**覆盖录制**：录制线扫过的旧内容被抹掉、换成新弹的音符（见下节）      |
| ■ 结束          | 清空音轨（音轨为空时不可点）；点击后弹窗二次确认「该操作将清空音轨中记录的数据，是否继续」 |
| 💾 保存         | 保存到「MIDI 播放器」的音乐库（浏览器本地），弹窗输入文件名，默认 `yyyyMMdd-hhmmss`        |
| ⬇ 下载          | 导出 `.mid` 文件下载，弹窗输入文件名，默认 `yyyyMMdd-hhmmss.mid`                           |

结束、保存、下载在**音轨为空时不可点击**。

## 覆盖录制（重录某一段）

录制是**覆盖式**的：点录制后，录制线从起点向前扫，**扫过的旧内容会被抹掉**，换成这一段新弹的音符；
**录制线还没到的地方不会被抹**——所以你能看到旧音符在录制线走过时被一点点吃掉。

- 音符被录制线**扫过一半**：只抹掉被扫到的那一半，录制线前面的部分留着；
  若线的起点落在音符中间，音符在起点之前的部分同样保留；
- 想重录某一段：把音轨拖到那一段的起点，点录制重新弹即可（没弹到的部分会被抹成空白）；
- 暂停录制 = 结束这一次"扫过"（擦除到此为止落定）；再点录制会从当前线位置重新开始扫；
- 拖动音轨也是分段点：拖动只把到拖动起点为止的范围擦掉，松手后从新位置重新开始扫，
  因此来回拖动不会误抹没扫过的区域；
- 想整条清空请用「结束」（不可撤销，有二次确认）。

## 移动录制/播放位置

在音轨上**左右拖动**即可移动录制/播放线：内容跟手（向右拖 = 回到更早的位置，向左拖 = 前往更晚的位置），
时间轴不会小于 0。**播放或录制过程中拖动时，拖动期间不播放也不录制**，松手后从新位置继续播放/录制。

例如：录完一段后想重录中间两小节——把音轨拖到目标位置，点录制重新弹；
想检查某处就播放时拖到那里，松手即从该处继续播放。

## 连接 MIDI 键盘

- 未检测到 MIDI 键盘时，**播放与录制按钮不可点击**；鼠标悬停（或点击）按钮会弹出 Tips
  「请先连接 MIDI 键盘」；
- 已连接时计时器右侧显示键盘名称；未连接时该处不显示提示（避免与按钮 Tips 重复），
  授权被拒 / 浏览器不支持 Web MIDI 时，把鼠标移到禁用的播放或录制按钮上会看到具体原因；
- 键盘在录制/播放中途被拔出会**自动暂停**（已录内容保留），插回后继续即可；
- 播放与录制监听都通过键盘自身音源发声（连接后程序会关闭键盘的 Local Control 以避免叠音，
  因此弹奏的按键由程序回送到键盘）。若键盘只有 MIDI 输入没有输出端口，则回放不会出声。

## 文件去向

- **下载**：`.mid` 文件（Format 1，480 PPQ，默认 120 BPM，4/4），通道信息保留；
- **保存**：写入浏览器本地音乐库（IndexedDB），回到「MIDI 播放器」工具即可在左侧「音乐库」
  看到该文件并直接播放（保存的名字会自动补 `.mid` 后缀）。

## 音轨会保留到什么时候

- 只要不点「结束」、不刷新页面，音轨内容一直在：**切到「MIDI 播放器」等其它工具再切回来，
  音轨与录制/播放线位置都会保留**（方便录完去看一眼保存结果）；
- 刷新或关闭页面后音轨不再保留（这是内存中的临时录制）——需要长期留存请用「保存」或「下载」；
- 「结束」会清空音轨且不可撤销（有二次确认）。

## 已知限制

- 88 键全部显示在一条音轨里，行高较密（窗口越高越宽松）；88 键之外的 MIDI 音不画但会被录制导出；
- 没有节拍器与量化，音符时间就是实际弹奏时刻；导出速度为固定的 120 BPM（时值按秒换算）；
- 一条音轨（多通道录制会显示在同一音轨里），没有撤销；局部重录用覆盖录制，整体重来用「结束」；
- 覆盖录制会一并抹掉扫过区间里的所有音高（这正是"覆盖"的含义）——只想补一个声部时，
  请把线停在要补的位置之后，别让线扫过原来的内容。
